## 功能亮点

- **管理员登录**：支持登录、退出和管理员身份校验
- **视频审核列表**：按待审核、已通过和未通过状态分页查看投稿视频
- **视频审核详情**：查看视频、封面、标题、简介、标签、分区和投稿人信息
- **审核操作**：支持通过或驳回投稿，驳回时填写审核原因
- **审核队列切换**：可在详情页继续查看上一条或下一条审核内容
- **外部视频线路与首次导入**：创建本地作品/剧集草稿，确认来源线路与统一时长，上传封面并首次导入为待审核视频（不发布、不自动审核）
- **后台导航布局**：提供首页、内容管理、审核管理、案件管理和系统管理等菜单
- **响应式侧边栏**：适配桌面端和小屏设备的后台导航
- **路由守卫**：依据本地 Token 保护管理页面
- **统一请求处理**：集中处理请求错误、登录失效和页面跳转
- **功能降级挡板**：尚未完成的管理功能显示未开放状态，避免无效请求

## 这是什么？

**菲比啾比管理端（feibijiubi-admin）** 是菲比啾比视频社区的管理员单页应用。本仓库基于开源项目 `teriteri-admin` 二次开发，并已对接菲比啾比 Spring Boot 后端。

项目当前主要覆盖管理员登录和视频审核链路：

```text
管理员登录
    -> 校验管理员身份
    -> 查看视频审核列表 -> 查看视频详情
    -> 审核通过 / 填写原因并驳回
```

## 安装与运行

### 环境要求

- Node.js 16 或更高版本
- npm
- 已启动的菲比啾比后端服务

### 安装依赖

```bash
npm install
```

### 启动开发环境

先启动后端服务（`https://github.com/linxi623/feibijiubi.git`，默认 `http://localhost:8080`），再运行：

```bash
npm run serve
```

浏览器访问 `http://localhost:8788`。
